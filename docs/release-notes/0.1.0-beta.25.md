# Rosetta 0.1.0-beta.25

Rosetta beta.25 adds a local PDF-to-Markdown workflow alongside the existing
layout-preserving PDF translation. It extracts structured text and local image
references into Rosetta's existing translation, preview, recovery, and export
pipeline without uploading document content.

## Highlights

- Adds Markdown as a selectable output for text-based PDF documents while
  preserving the existing translated-PDF workflow.
- Extracts headings, paragraphs, lists, tables, captions, footnotes, pictures,
  and formulas into a deterministic, page-aware Markdown representation.
- Adds managed PDF-to-Markdown component controls under Settings → PDF
  Processing, including install, repair, reinstall, cancellation, status
  inspection, and validated offline archive import.
- Restores partial translation progress after restart and enables Markdown
  export only after every translatable segment is complete.
- Synchronizes source and translated Markdown scrolling in either direction
  without letting virtual-list measurements or programmatic scroll events form
  feedback loops.
- Exports Markdown and its local image assets as one transactional result;
  replacement failures restore the previous complete export.
- Adds a headless release acceptance suite covering state restoration, runtime
  isolation, translation/export lifecycle, rollback, and the 24-document /
  240-page extraction corpus.

## Supported Platforms For This Release

- Windows 10/11 x64. Unless the installer is Authenticode-signed, this build is
  published as Windows Preview.
- macOS 13 or newer on Apple Silicon.
- Ubuntu 24.04 or newer on Linux x64.

Rosetta remains local-first. PDF content, extracted Markdown, translations,
images, and runtime logs stay on the user's device.
