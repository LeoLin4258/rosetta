# Rosetta 0.1.0-beta.23

Rosetta beta.23 substantially improves PDF preparation, visual translation
fill-back, partial-failure handling, navigation, and long-document storage.

## Highlights

- Reduced the ten-page benchmark's first PDF preparation from about 7.5
  seconds to about 3 seconds while preserving the established RWKV translation
  request plan and throughput.
- Restored the mature pdf2zh visual rendering path and improved fill-back for
  tables, contents pages, colored backgrounds, references, and complex paper
  layouts.
- Preserves only an individual failed translation unit when model output is
  incomplete, allowing the rest of the page to render translated content
  instead of failing the whole page.
- Added a PDF page map, direct page navigation, clearer page selection, and
  more precise translation progress and document states.
- Compresses translated page artifacts in the background and bounds durable
  PDF caches to prevent long documents from continuously growing job storage.
- Updates the managed PDF component for Windows x64 and macOS Apple Silicon,
  including stricter artifact validation and component compatibility checks.

## Supported Platforms For This Release

- Windows 10/11 x64.
- macOS 13 or newer on Apple Silicon.

The Linux App release is deferred while its PDF preparation performance is
re-evaluated. Existing Linux installations remain on the previous published
PDF component.

Rosetta remains local-first. Documents, translations, PDF caches, prompts, and
runtime logs stay on the user's device and are not uploaded by the release or
update system.
