# Rosetta 0.1.0-beta.20

Rosetta beta.20 focuses on PDF translation quality and the updated PDF
component packs validated on both Windows x64 and macOS Apple Silicon.

## Highlights

- PDF component packs have been updated on Windows and macOS with the July
  structured-content preservation fixes.
- PDF translation now preserves more complex tables, mathematical formulas,
  algorithm boxes, and diagram labels in the original layout when they cannot
  be safely translated as body text.
- Duplicate PDF text layers are filtered more conservatively, reducing
  translated text overlap, hidden English leftovers, and placeholder mismatch
  failures.
- PDF rendering is more tolerant of replay order drift, avoiding failures seen
  on some macOS pages after layout preparation succeeded.
- The PDF component bundles the BabelDOC fonts required by Rosetta, reducing
  first-run failures caused by runtime font downloads.
- Rosetta now checks the installed PDF component manifest against the current
  release profile, so older beta PDF packs are treated as needing update
  instead of being reused silently.

## Supported platforms

- Windows 10/11 x64.
- macOS 13 or newer on Apple Silicon.

Rosetta remains local-first. Documents, translations, job caches, prompts, and
runtime logs are not uploaded by the release or update system.
