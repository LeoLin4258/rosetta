# Rosetta 0.1.0-beta.24

Rosetta beta.24 brings Linux back onto the same release line as Windows and
macOS, with a stabilized and auditable Linux PDF component. It preserves the
PDF translation, preview, export, and local cache behavior accepted in
beta.23.

## Highlights

- Releases Windows x64, macOS Apple Silicon, and Linux x64 from the same app
  version and source commit.
- Brings beta.23's PDF preparation, visual fill-back, partial-failure handling,
  page navigation, and bounded long-document storage improvements to Linux.
- Improves Linux PDF preparation performance and makes completed layout work
  reusable across jobs and restarts without changing the established RWKV
  request plan or translation-unit authority.
- Hardens PDF component installation with download and extraction limits,
  disk-space checks, cancellation, and transactional rollback for failed
  fresh installs or upgrades.
- Restores installation and worker-start compatibility for the pinned
  official Windows and macOS PDF component archives while keeping custom or
  modified packs fail-closed.
- Keeps first-run onboarding lifecycle-safe: closing it exits cleanly on
  Windows/Linux, while macOS Dock reopen restores the window selected by the
  current onboarding state instead of bypassing setup.
- Pins the Linux PDF dependency graph and external build inputs, and publishes
  inventory, size, SBOM, license, and build-recipe evidence for the component.
- Removes the unused native PDF v3 experiment and its dependencies while
  retaining the production pdf2zh translation, preview, export, and canonical
  source-identity path.

## Supported Platforms For This Release

- Windows 10/11 x64. Unless the installer is Authenticode-signed, this build is
  published as Windows Preview.
- macOS 13 or newer on Apple Silicon.
- Ubuntu 24.04 or newer on Linux x64.

Rosetta remains local-first. Documents, translations, PDF caches, prompts, and
runtime logs stay on the user's device and are not uploaded by the release or
update system.
