# Rosetta 0.1.0-beta.22

Rosetta beta.22 makes PDF background preparation reusable across document
switches and application restarts.

## Highlights

- Keeps multiple prepared PDF windows in a bounded in-memory cache, so moving
  between recently used documents no longer repeats the full prepare pipeline.
- Persists compressed PDF layout results inside each local job and restores
  them after Rosetta or its PDF worker restarts.
- Shows a restrained prepared indicator in the document sidebar and restores
  it from validated local cache metadata at startup.
- Adds dedicated PDF, Markdown, and text document icons and reduces visual
  weight in partial-translation status and row interactions.
- Validates cached results against the source document, selected pages,
  language direction, PDF engine, and layout model; stale or corrupt entries
  safely fall back to normal preparation.
- Bounds durable derived data to 12 entries and 256 MB per PDF job, with
  least-recently-used eviction.

## Supported Platforms

- Windows 10/11 x64.
- macOS 13 or newer on Apple Silicon.
- Ubuntu 24.04 or newer on x86_64.

Rosetta remains local-first. PDF preparation caches stay on the user's device
and do not contain source text, translations, prompts, or model responses.
