# Rosetta 0.1.0-beta.21

Rosetta beta.21 introduces the first public Linux x64 release path and improves
PDF translation throughput and model-input stability across platforms.

## Highlights

- Added an AppImage release for Ubuntu 24.04 or newer on x86_64, using the same
  signed Supabase in-app updater channel as Windows and macOS.
- Added managed Linux runtimes with RWKV Lightning CUDA preferred on supported
  NVIDIA GPUs and llama.cpp Vulkan available as the compatibility path.
- Added an online-installable Linux PDF layout component and bundled Linux x64
  PDFium support.
- Added background PDF preparation and in-process prepared-window reuse to
  reduce repeated layout-analysis work before translation.
- Improved PDF unit and reference-list segmentation to avoid oversized model
  batches, tiny fragment requests, missing reference entries, and repetition.
- Added privacy-safe full-batch request capture for reproducible local model
  diagnostics when I/O debug mode is explicitly enabled.
- Fixed AppImage Python environment leakage and Linux close-to-exit cleanup for
  managed RWKV and PDF worker processes.

## Supported Platforms

- Windows 10/11 x64.
- macOS 13 or newer on Apple Silicon.
- Ubuntu 24.04 or newer on x86_64.

Rosetta remains local-first. Documents, translations, job caches, prompts, and
runtime logs are not uploaded by the release or update system.
